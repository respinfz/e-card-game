# Identificadores de dominio en español

Los tipos, funciones y variables del dominio usan las mismas palabras que `GLOSSARY.md` (`Ronda`, `Enfrentamiento`, `cartaEsclavo`, `Apuesta`) en lugar de traducirlas al inglés. Así el código y el glosario hablan el mismo idioma y no hace falta una tabla de equivalencias que se desactualice. Las palabras clave del lenguaje y los nombres técnicos genéricos siguen en inglés.
